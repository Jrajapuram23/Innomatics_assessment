# Food Delivery Data Analysis

This repository contains a Jupyter Notebook that analyzes food delivery data by merging:
- orders.csv (transaction data)
- users.json (user master data)
- restaurants.sql (restaurant master data)

## Files
- food_delivery_analysis.ipynb : Main analysis notebook
- orders.csv : Order transactions
- users.json : User details
- restaurants.sql : Restaurant details
- final_food_delivery_dataset.csv : Merged dataset

## Description
The notebook loads the datasets, performs left joins on user_id and restaurant_id, and analyzes:
- Revenue by city and membership
- Cuisine-wise performance
- User behavior
- Time-based trends

## How to run
Open the notebook and run all cells from top to bottom.
